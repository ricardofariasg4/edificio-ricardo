# Projeto Edifício Ricardo

## Sobre o Projeto
Sistema de gestão de portaria desenvolvido para otimizar a comunicação entre o condomínio e seus moradores. 

Este repositório contém o **backend** da aplicação, responsável por:
- Fornecer API para o sistema desktop da portaria
- Servir dados para os aplicativos mobile dos moradores
- Gerenciar autenticação, notificações e registros de eventos
